║  cat      │  Change AT  │  Around tag change                ║
║  vit      │  Visual IT  │  Visual select inner              ║
║  vat      │  Visual AT  │  Visual select around             ║

║                  INDENTATION COMMANDS                        ║
╠═══════════════════════════════════════════════════════════════╣
║                                                               ║
║  COMMAND  │  WHAT IT DOES                                    ║
║  ─────────┼───────────────────────────────────────────────── ║
║  >>       │  Current line indent (right)                    ║
║  <<       │  Current line dedent (left)                     ║

║  >at      │  Indent around tag (poora tag)                  ║

║  =at      │  Auto-indent around tag                         ║
║  gg=G     │  Auto-format entire file                        ║
